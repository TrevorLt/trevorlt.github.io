# Trevor Lin

Personal portfolio at **https://trevorlt.github.io/**.

A buildless site served by GitHub Pages from `main` at the repository root. The BattleBot preview loads Model Viewer from its CDN; no local packages are needed.

## Local preview

```sh
python3 -m http.server 4173
```

Open http://localhost:4173. Edit `index.html`, `styles.css` and `script.js`. Fonts and images are hosted locally. The scan illustration is procedural and does not represent measured results. The Codex display study uses illustrative values and provides double-ring, large-readout and quota-state controls.

## Regression checks

With the preview server running, open http://localhost:4173/tests/browser.html. The page checks saved quota values, recharge and mode switching, both displays, interrupted animations, invalid URL values, rapid disclosure reversals, and the BattleBot GLB structure, 2206 cross mount on the source upright plate's four-hole pattern, aligned motor and weapon pulleys with a direct belt, replaceable-armor separation, rear motors and wheel motion, reversible exploded view, and fast drivetrain controls. It shows PASS or FAIL without local packages; the 3D preview loads Model Viewer from its CDN.

Selected projects include BattleBot (CAD assembly), CryptScan (in development), and Codex Usage Status. The BattleBot is an Antweight vertical spinner with replaceable 3D-printed ABS armor designed for quick swaps between matches or after damage. Its preview uses Google Model Viewer 4.4.0 with a local Onshape GLB export, an exploded armor-removal animation, a 2206 brushless motor (22 mm diameter × 6 mm stator) cross-mounted to the source assembly's upright four-hole plate, a direct parallel-axis timing-belt weapon drive, and two rear brushed motors that animate the original wheels. The source assembly and native wheels are preserved; the added hardware is a visualization and has not been physically fit-checked, and the linked Onshape document remains unchanged.
