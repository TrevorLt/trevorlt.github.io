# Trevor Lin

Personal portfolio at **https://trevorlt.github.io/**.

A buildless, dependency-free site served by GitHub Pages from `main` at the repository root.

## Local preview

```sh
python3 -m http.server 4173
```

Open http://localhost:4173. Edit `index.html`, `styles.css` and `script.js`. Fonts and images are hosted locally. The scan illustration is procedural and does not represent measured results.
